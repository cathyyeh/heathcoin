# 健康幣健康促進平台原型

這個專案是一個以「健康幣」為主題的研究導向靜態前端原型，內容以台灣衛福部健康署的健康促進與健康治理策略為背景，聚焦在健康檢查、健康行為獎勵、家庭照護、社區健身與長照支持等延伸場景。

## 專案目標

本原型以研究成果與設計概念為背景，展示健康幣的定位與可能的延伸：

* 將健康檢查、健康追蹤與健康任務整合成一個可累積的健康幣機制
* 擴展健康幣至健身、步數挑戰與社區健康活動
* 將長照志工服務、家庭照護與高齡健康關懷納入獎勵流程
* 探索健康幣與生活資源、健康資源兌換間的可行對應

## 主要內容

本專案主要以一個單頁式儀表板形式呈現，使用者可於頁面中看到：

* 健康幣帳戶總覽
* 今日任務與挑戰任務列表
* 可兌換資源
* 四個核心使用案例
* 不同 Persona 的任務推薦與健康幣加成視角

## 使用案例

本原型包含四個主要設計情境：

1. 健康檢查與步數挑戰

   使用者完成健康檢查與風險評估後，可獲得健康幣與健康行為追蹤任務

2. 家庭健康照護任務

   家庭成員完成健康回報、血壓紀錄、作息與照護任務，產生家庭照護加成

3. 社區健身與運動挑戰

   健康幣與運動幣可形成雙向機制，鼓勵居民參與社區步數、健康活動與體適能任務

4. 長照志工與照護支持

   長照2.0 相關服務時數與照護貢獻可映射為健康幣或加值獎勵

## 專案結構

* `index.html`：整體儀表板與頁面內容
* `styles.css`：全域設計與版面風格
* `app.js`：互動行為與 Persona 切換邏輯
* `combined_healthcoin_research.md`：研究整合版報告
* `healthcoin_research_report.md`：研究報告摘要
* `healthcoin_demo_design.md`：Demo design 與 use case 設計文件
