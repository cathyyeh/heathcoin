# 健康時間經濟原型

這個專案為健康幣 2.0 的研究導向靜態前端原型，內容以台灣衛福部健康署與長照政策場域為背景，重新定義健康價值的表現方式：不再以單純的獎勵點數說明，而是以「健康時間」作為可創造、可保存、可分享、可在未來需求時回流使用的公共健康資產。

## 專案目標

本原型以研究成果與設計概念為背景，展示健康時間經濟的定位與可能的延伸：

* 將健康檢查、健康追蹤與健康任務整合為創造健康時間的入口
* 擴展健康時間至家庭陪伴、志工貢獻與社區健康支持
* 將長照照護與未來支持需求納入健康時間的使用情境
* 探索健康時間與公共資源、照護服務、社區支持之間的可行對應

## 主要內容

本專案主要以一個單頁式儀表板形式呈現，使用者可於頁面中看到：

* 可用健康時間與健康時間流向
* 今日任務與健康行動進度
* 可使用的健康資源與照護支持入口
* 四個核心使用案例
* 不同 Persona 的任務推薦與健康時間價值視角

## 使用案例

本原型包含四個主要設計情境：

1. 健康檢查與健康行動

   使用者完成健康檢查與健康回報後，可創造健康時間，並於日後獲得更清楚的健康支持引導

2. 家庭健康照護任務

   家庭成員完成健康回報、血壓紀錄、作息與照護任務，形成家庭層級的健康時間支持

3. 社區支持與志工貢獻

   志工陪伴、社區活動與服務貢獻可轉為健康時間，強化社區參與與互助價值

4. 長照與未來支持

   長照服務、照護需求與未來健康支援，可透過健康時間的回流機制形成更有彈性的資源安排
